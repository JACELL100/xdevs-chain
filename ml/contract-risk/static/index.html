xDEVS Contract Risk

Scores a contract's bytecode for patterns seen in malicious contracts: wallet drainers, exploit and phishing contracts. Built for the safety checks of xDEVS Chain. The model runs in your browser; nothing is sent anywhere except the code lookup to the network's RPC. Model card.

A score is advice, not proof: it means the code resembles malicious code in the training data. Proxies point to an implementation: score that address too.

Model: LightGBM blended with logistic regression, trained on Ethereum contracts from Forta's MIT datasets · source · by THE xDEVS
